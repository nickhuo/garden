### Agent frameworks & self-evolution

#### 🟢 [2606.01311] SkillAdaptor — step-level skill 自适应，可插 OpenClaw
- **Problem:** 现有 training-free skill 适配从整条 trajectory 更新，failure 归因太粗、改动不稳。
- **Method:** SkillAdaptor——定位「首个 actionable 错误步」，把责任 link 到候选 skill，在显式 acceptance check 下做 targeted 更新，backbone 冻结；可插入 OpenClaw 类 harness。
- **Key result:** 三套 benchmark 全面提升；最大单项 +1.7 WebShop 成功率、+1.8 Claw-Eval、+1.5 PinchBench。
- *Links:* [PDF](https://arxiv.org/pdf/2606.01311) · [HF](https://huggingface.co/papers/2606.01311)

#### 🟢 [2605.30723] MASA — skill 是 model-dependent，要按 backbone 对齐
- **Problem:** skill 库通常被当 model-agnostic 复用，但同一条 skill 对一个模型有益、对另一个有害。
- **Method:** MASA（Model-Aware Skill Alignment）——hill-climbing + UCB 树搜索的分层 skill 进化，再蒸馏成一个 model-conditioned rewriter，单次 forward 完成适配，不改 agent 权重。
- **Key result:** 三环境四 backbone 全面最优，较最强 baseline 最高 **+25.8** 分；rewriter 泛化到未见任务且推理成本远低于 teacher。
- *Links:* [PDF](https://arxiv.org/pdf/2605.30723) · [HF](https://huggingface.co/papers/2605.30723)

#### 🟡 [2605.30611] Crafter — 可编辑科学图生成的多 agent harness
- **Problem:** 现有自动绘图只支持单一图型 + 纯文本输入，输出是不可局部修改的 raster。
- **Method:** Crafter（多 agent harness，跨图型/输入条件无需改架构）+ CraftEditor（raster→可编辑 SVG）+ CraftBench 基准。
- **Key result:** 在 PaperBanana-Bench / CraftBench 上显著超过独立生成器与 agentic baseline；摘要未给具体数值。
- *Links:* [PDF](https://arxiv.org/pdf/2605.30611) · [HF](https://huggingface.co/papers/2605.30611)

#### 🟡 [2606.01528] Joint Agent Memory and Exploration via Novelty Signals
- **Problem:** agent 的记忆与探索通常分开处理，长程任务里二者本应耦合。
- **Method:** 用 novelty 信号联合学习 agent 的记忆写入与探索策略（详见正文）。
- **Key result:** 摘要未抓取到具体指标（仅 title/榜单信息）。
- *Links:* [PDF](https://arxiv.org/pdf/2606.01528) · [HF](https://huggingface.co/papers/2606.01528)

### Agent reliability, evaluation & safety

#### 🟢 [2605.28556] TASTE — 反向造题，破解 agent 基准饱和
- **Problem:** τ²-Bench 等 agent 基准日益饱和；传统「先写自然语言再映射工具序列」只覆盖很窄的 tool-use 模式。
- **Method:** TASTE（Task Synthesis from Tool Sequence Evolution）——用 Adaptive Contrastive n-gram 采样合法工具序列，聚类选代表序列，迭代难度进化，构出 τc-Bench。
- **Key result:** 近乎刷穿 τ²-Bench 的模型在新题上暴跌（Gemini-3-Flash 0.82–0.94 → 0.28–0.61），独特工具组合数翻倍以上。
- *Links:* [PDF](https://arxiv.org/pdf/2605.28556) · [HF](https://huggingface.co/papers/2605.28556)

#### 🟢 [2606.01533] MACU — 多 agent 计算机操作
- **Problem:** computer-use agent 多为单条串行，长程任务缺少分解、并行、再规划。
- **Method:** MACU——manager 把任务拆成 DAG，每轮并行派发 CUA 子 agent 跑 ready frontier，并随新发现持续改写 DAG；部分可观测信息经 manager/DAG 前向保留。
- **Key result:** 在 OSWorld / Online-Mind2Web / WebTailBench / Odysseys 较单 agent 提升 **3.4–25.5%**；Odysseys 上平均完成 wall-clock 提速约 1.5×。
- *Links:* [PDF](https://arxiv.org/pdf/2606.01533) · [HF](https://huggingface.co/papers/2606.01533)

#### 🟢 [2606.02470] MCP-Persona — 真实个人应用上的 MCP agent 基准
- **Problem:** 现有基准多聚焦通用信息检索工具，没覆盖「工具直接操作个人账号/本地库」的社交/协作场景。
- **Method:** MCP-Persona——首个面向真实个性化 MCP 工具的基准，涵盖 Reddit、小红书、飞书(Lark)、Slack 等。
- **Key result:** SOTA agent 在个性化工具使用上「显著挣扎」；摘要未给具体数值。
- *Links:* [PDF](https://arxiv.org/pdf/2606.02470) · [HF](https://huggingface.co/papers/2606.02470)

#### 🟡 [2606.00408] Masking Stale Observations Helps Search Agents — Until It Doesn't
- **Problem:** 给 search agent 屏蔽过时观测能提升表现，但何时反而有害？
- **Method:** 给出一张 regime map + 机制解释，刻画 masking 收益/损害的边界。
- **Key result:** 摘要未抓取到具体指标。
- *Links:* [PDF](https://arxiv.org/pdf/2606.00408) · [HF](https://huggingface.co/papers/2606.00408)

#### 🟡 [2606.00660] FineVerify — 细粒度自验证扩展 agentic search 的 test-time compute
- **Problem:** agentic search 的 test-time 扩展缺乏细粒度验证信号。
- **Method:** FineVerify——细粒度 self-verification 来 scale test-time compute。
- **Key result:** 摘要未抓取到具体指标。

### Post-training (RL, distillation, scoring)

#### 🟢 [2605.24202] 多 agent RL 何时真能改进 LLM workflow？
- **Problem:** 多 agent workflow 用 RL 端到端联训不稳，机制不清。
- **Method:** 对比 Shared-Policy（所有角色共享一套参数）vs Isolated-Policy（每角色独立），矩阵覆盖 Eval-Opt/Voting/Orch-Workers × 数学/代码 × 0.6B/1.7B/4B，并用角色级梯度动力学解释失败模式。
- **Key result:** 多 agent RL 通常优于 base，但收益取决于 workflow×任务×scale 而非「是否共享」；Isolated 峰值更高但更易掉「terminal accuracy cliff」。
- *Links:* [PDF](https://arxiv.org/pdf/2605.24202) · [HF](https://huggingface.co/papers/2605.24202)

#### 🟡 [2605.29860] ESPO — Early-Stopping PPO

- *Links:* [PDF](https://arxiv.org/pdf/2605.29860) · [HF](https://huggingface.co/papers/2605.29860)

#### 🟡 [2606.01682] 把现成 LLM 当 Process Scorer——免训练替代 PRM

### Retrieval / RAG / memory

#### 🟢 [2606.02373] Harness-1 — 把 search 状态外置到环境侧 harness
- **Problem:** search agent 被迫在 policy 里同时做语义检索决策 + 大量可恢复的「记账」状态管理，RL 优化负担过重。
- **Method:** Harness-1（20B 检索子 agent）在 stateful harness 内用 RL 训练——harness 维护候选池、重要性标注集、证据链接、验证记录、去重压缩观测、预算感知渲染；policy 只保留语义决策（搜什么/留弃/验证/何时停）。
- **Key result:** 8 个检索基准平均 curated recall **0.730**，较次强开源 search 子 agent **+11.4** 分，held-out 迁移基准上提升尤为明显。
- *Links:* [PDF](https://arxiv.org/pdf/2606.02373) · [HF](https://huggingface.co/papers/2606.02373)

#### 🟡 [2606.01336] LongAttnComp — 跨族长上下文压缩

- **Method:** LongAttnComp——cross-family 的上下文压缩用于 long-context reasoning。
- **Key result:** 摘要未抓取到具体指标（与 Part 1 的 headroom / context-mode 同主题，工程↔研究可串）。
