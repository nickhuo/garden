### Agent reliability, evaluation & safety

### 🟢 [2606.13174] Trace — 把用户纠正编译成运行时强制规则
- **Problem:** coding agent "记住"了你的纠正却不照做；即便规则在 context 里，agent 也只满足不到一半的检查。
- **Method:** Trace（Test-time Rule Acquisition + Compiled Enforcement）——检测纠正→抽取原子规则→用五种生命周期动作(Noop/Update/Supersede/Split/New)消解→编译成任务完成前必须通过的可执行检查。
- **Key result:** ClawArena 违规率 100% → 37.6%（同分布）/ 2.0%（OOD）；所需纠正轮次 2.00 → 1.37。
- *Links:* [PDF](https://arxiv.org/pdf/2606.13174) · [HF](https://huggingface.co/papers/2606.13174)
- *为什么对你重要：* 这正是 `CLAUDE.md` 规则"被记住但不被遵守"问题的学术化解法——可直接启发你 self-improving rules 的工程化。

### 🟢 [2606.07867] SODA — LLM agent 的 cold-start 安全缺口
- **Problem:** agent 在会话**开始时最不安全**，跑过若干常规任务后才逐渐变安全——现有安全基准都在孤立会话里评测，漏掉了这一点。
- **Method:** SODA 基准，400 个安全威胁 × 8 个会话深度(D=0…20)，测 7 模型 4 家族 + PCA 表征分析。
- **Key result:** D=0→20 安全性提升 **9–52%**；AgentHarm +23%；建议部署前用 **5–10 个常规任务热身**，零效用损失。
- *Links:* [PDF](https://arxiv.org/pdf/2606.07867) · [HF](https://huggingface.co/papers/2606.07867)

### Code / web agents

### 🟡 [2606.10423] WebChallenger — 靠架构追平的通用 web agent
- **Problem:** 开源小模型 web agent 在长程导航上远逊闭源，瓶颈不在推理力而在架构。
- **Method:** PageMem（DOM 派生的分层页面表示）+ 三机制：分而治之的选择性观察、离线探索建持久站点记忆、复合动作工作流。
- **Key result:** 现成 32B/7B 无微调下 WebArena 56.3%（开源 SOTA）、WorkArena 70.9%、Online-Mind2Web 51.0%。
- *Links:* [PDF](https://arxiv.org/pdf/2606.10423) · [HF](https://huggingface.co/papers/2606.10423)
