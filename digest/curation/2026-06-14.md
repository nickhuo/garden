### TL;DR — 本日 research 风向

### Agent frameworks & self-evolution

#### 🟡 [2606.13681] EvoArena / EvoMem — 环境演化下的 agent 记忆
- **Problem:** 现有 agent 评测假设静态环境，真实部署需随环境/任务持续对齐知识与行为。
- **Method:** EvoArena 把环境变化建模为 terminal/software/social 域的渐进更新序列；EvoMem 用 patch-based 记忆记录结构化更新历史。
- **Key result:** 当前 agent 平均仅 39.6%；EvoMem 在 EvoArena +1.5%，GAIA/LoCoMo 分别 +6.1%/+4.8%。
- *Links:* [PDF](https://arxiv.org/pdf/2606.13681) · [HF](https://huggingface.co/papers/2606.13681)

#### 🟢 [2606.12882] HarnessBridge — 可学习的 agent harness 控制器
- **Problem:** 手工编写的 agent-环境 harness 难以随长程、复杂交互 scale。
- **Method:** 把接口参数化为双向投影（observation 投影压缩轨迹为决策状态，action 投影把动作转成可执行迁移/拒绝），统一指令微调训练。
- **Key result:** 在 Terminal-Bench 2.0 与 SWE-bench Verified 上「匹配或超越专用 harness，同时大幅降低 token 与轨迹长度」。
- *Links:* [PDF](https://arxiv.org/pdf/2606.12882) · [HF](https://huggingface.co/papers/2606.12882)

### Inference optimization & compiler

#### 🟡 [2606.13392] MiniMax Sparse Attention (MSA) — 1M 上下文的块稀疏注意力
- **Problem:** softmax 注意力的二次成本，使百万级 token 上下文在部署规模不可行。
- **Method:** 基于 GQA 的 blockwise 稀疏注意力：轻量 Index Branch 为每组选 Top-k KV 块，Main Branch 只对选中块做精确稀疏注意力；co-design exp-free Top-k 与 KV-outer 内核。
- **Key result:** 109B 模型上与 GQA 持平，1M 上下文下注意力算力降 **28.4×**；配套内核 prefill **14.2×**、decoding **7.6×**（H800）。
- *Links:* [PDF](https://arxiv.org/pdf/2606.13392) · [HF](https://huggingface.co/papers/2606.13392)

#### 🟢 [2606.13174] Getting Better at Working With You (TRACE) — 把用户纠正编译成运行时强制
