## Part 2 — Research Radar（HuggingFace Papers）

### TL;DR — 本日 research 风向
今天 HF 榜被**智能体记忆与长程评估**主导：GateMem（多主体共享记忆治理基准）和 WorldLines（长程有状态具身智能体基准）双双高赞，配合 RAG 侧的两篇检索改进（SproutRAG / MCompassRAG），整体指向「记忆 + 检索 + 评估」这条 Nick 求职最对口的线。其余多模态/医学影像论文与 Nick agenda 弱相关，已 drop。

> 注：以下 Problem / Method / Key result 基于 HF 列表摘要（无完整 abstract），凡摘要未给数字处一律如实标注「No quantitative result reported」，绝不编造 metric。

### Agent reliability, evaluation & safety
### 🟢 [2606.18829] GateMem — 多主体共享记忆治理基准
- **Problem:** 多智能体共享同一记忆时，谁能读写、如何隔离与治理缺乏评测标准。
- **Method:** 提出 Memory Governance 基准，评估 multi-principal shared-memory agent 的访问控制与冲突治理。
- **Key result:** No quantitative result reported（摘要未给具体数字）。
- *Links:* [PDF](https://arxiv.org/pdf/2606.18829) · [HF](https://huggingface.co/papers/2606.18829)

### 🟡 [2606.18847] WorldLines — 长程有状态具身智能体基准
- **Problem:** 现有评测难以衡量智能体在长时间跨度内对状态的维持与推理能力。
- **Method:** 构建 long-horizon stateful embodied agent 的基准与建模框架。
- **Key result:** No quantitative result reported。
- *Links:* [PDF](https://arxiv.org/pdf/2606.18847) · [HF](https://huggingface.co/papers/2606.18847)

### Retrieval / RAG / memory
### 🟡 [2606.18381] SproutRAG — 注意力引导的树搜索长文档 RAG
- **Problem:** 长文档检索中，扁平 chunk 检索丢失结构、召回质量差。
- **Method:** Attention-guided tree search 配合 progressive embeddings 做层级检索。
- **Key result:** No quantitative result reported。
- *Links:* [PDF](https://arxiv.org/pdf/2606.18381) · [HF](https://huggingface.co/papers/2606.18381)

### 🟡 [2606.18508] MCompassRAG — 主题元数据作为段落检索的语义罗盘
- **Problem:** 段落级检索缺乏全局主题导航，易召回离题片段。
- **Method:** 用 topic metadata 作为 semantic compass 引导 paragraph-level 检索。
- **Key result:** No quantitative result reported。
- *Links:* [PDF](https://arxiv.org/pdf/2606.18508) · [HF](https://huggingface.co/papers/2606.18508)

### 🟡 [2606.17162] MemSlides — 分层记忆驱动的个性化 PPT 生成智能体
- **Problem:** 自动生成幻灯片缺乏个性化与多轮局部修改能力。
- **Method:** 分层记忆（hierarchical memory）驱动的 agent 框架，支持 multi-turn local revision。
- **Key result:** No quantitative result reported。
- *Links:* [PDF](https://arxiv.org/pdf/2606.17162) · [HF](https://huggingface.co/papers/2606.17162)

### Post-training / prompt engineering
### 🟡 [2606.15641] Distilling Examples into Task Instructions — 把示例蒸馏成任务指令
- **Problem:** 真实 B2B 对话场景里 few-shot 示例占 context、可迁移性差。
- **Method:** 将 in-context 示例蒸馏为显式 task instructions，增强 ICL。
- **Key result:** No quantitative result reported。
- *Links:* [PDF](https://arxiv.org/pdf/2606.15641) · [HF](https://huggingface.co/papers/2606.15641)
