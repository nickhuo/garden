### Agent memory & self-evolution

#### 🟡 [2611.14326] When Should Agents Remember? Falsification-Gated Self-Evolution
- **Problem:** agent 随时间积累的记忆含错误或无关条目，自我进化偏向错误方向
- **Method:** Falsification-Gated Self-Evolution——只有通过证伪检验的记忆才被存储，拒绝未经验证的更新
- **Key result:** 无定量结果
- *Links:* [PDF](https://arxiv.org/pdf/2611.14326) · [HF](https://huggingface.co/papers/2611.14326)

#### 🟢 [2611.14320] Don't Just Trust Your Memory: Evidence-Linked Memory
- **Problem:** LLM agent 存储记忆积累错误，导致系统性性能退化
- **Method:** 给每条 agent 记忆挂接可溯源的证据链，抑制无根据记忆引发的错误传播
- **Key result:** 无定量结果
- *Links:* [PDF](https://arxiv.org/pdf/2611.14320) · [HF](https://huggingface.co/papers/2611.14320)
