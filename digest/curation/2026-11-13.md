## 📅 本周回顾（周五特辑）

### 高频主题

本周 GitHub Trending 被以下几条主线统治：

1. **Coding Agent 生态爆炸**：Claude Code、Codex、Qwen Code、Cursor 等多个 coding agent 的 skill / plugin / template 仓库持续涌现，ecosystem 进入 "百花齐放" 阶段。
2. **MCP 协议成熟期**：官方 Go SDK 上线，Chrome DevTools MCP、Blender MCP 等垂直领域 MCP server 加速落地——协议从 "概念" 进入 "生态铺设"。
3. **中文大厂开源发力**：Alibaba open-code-review、Tencent LoopForge / WeKnora、Volcengine OpenViking 四个仓库集中出现，说明国内头部公司在 agent infra 层的开源策略在加速。
4. **Agent 安全/可控性**：NVIDIA SkillSpector（安全扫描）、backnotprop/plannotator（审查工作台）标志着社区开始认真对待 agent 的可审计性，不再只追求能力。

### 最值得深挖的主题

**→ Agent 上下文管理层（context compression / management）**

headroom + OpenViking + WeKnora 三个仓库从不同角度解决同一问题：LLM 在长对话/大工具调用链里如何高效利用上下文。这是所有 AI 应用的性能瓶颈，也是大厂面试 System Design 题的高频场景。深挖这个方向可以出：一篇博客 + 一个 GitHub demo + 面试谈资三件套。
