### TL;DR — 本日 research 风向
本周 November 2026 arXiv 论文密集关注 **agent 评估与 benchmark 标准化**：coding agent 在企业 DSL（AgentScript-Eval，NeurIPS 2026）和程序优化（Accelerate Bench，Score@1 25.5%–67.4%）两端同步建立量化基准；「agents 能否自主构建新 agents」（Singularity-Bench）开始进入 benchmark 体系。并行子 agent 可靠性问题开始有系统性分析，RAG pipeline 自动化优化成熟（Agentic AutoRAG 进入 NeurIPS 2026 workshop）。

### Agent frameworks & self-evolution

### 🟢 [2611.16591] Singularity-Bench: Can Agents Build Agents? `[WSQ]`
- **Problem:** Agent 自主从 spec 构建并部署新 agent 的能力缺乏量化评估标准
- **Method:** 评估 LLM agents 能否从 specification 生成并部署新 agent 的 benchmark 框架
- **Key result:** No quantitative result reported
- *Links:* [PDF](https://arxiv.org/pdf/2611.16591) · [HF](https://huggingface.co/papers/2611.16591)

---

### Agent reliability, evaluation & safety

### 🟢 [2611.13183] AgentScript-Eval: Enterprise Agent DSL Benchmark `[WSQ]`
- **Problem:** 企业 AI agent DSL（如 Salesforce Agentforce）缺乏标准化代码质量基准
- **Method:** 100 个真实 Agentforce DSL 任务（authoring 30 / debugging 40 / optimization 30），NeurIPS 2026 accepted
- **Key result:** Accepted at NeurIPS 2026（quantitative details not extracted from abstract）
- *Links:* [PDF](https://arxiv.org/pdf/2611.13183) · [HF](https://huggingface.co/papers/2611.13183)

### 🟢 [2611.20882] Accelerate Bench: Coding Agents on Program Optimization `[WSQ]`
- **Problem:** Coding agent 在 CPU 程序优化任务上的能力缺乏多模型多 harness 量化评估
- **Method:** 32 个 CPU 优化任务（来自科学计算和超算竞赛），评估 16 个 coding agents（模型 × harness 组合）
- **Key result:** Score@1 范围 25.5%–67.4% across 16 coding agents（2.6× 差距）
- *Links:* [PDF](https://arxiv.org/pdf/2611.20882) · [HF](https://huggingface.co/papers/2611.20882)

### Code / web agents

### 🟡 [2610.10263] When Sub-Agents Work in Parallel: Promises and Pitfalls `[WSQ]`
- **Problem:** 长周期编码任务中 dynamic concurrency 子 agent 的失效模式和 overhead 不明确
- **Method:** 系统分析 dynamic concurrency 在 long-horizon coding 中的 trade-off、常见 pitfall 与适用场景
- **Key result:** No quantitative result reported
- *Links:* [PDF](https://arxiv.org/pdf/2610.10263) · [HF](https://huggingface.co/papers/2610.10263)

### Retrieval / RAG / memory

### 🟡 [2610.08452] Agentic AutoRAG: RAG Pipeline Optimization via Agents `[WSQ]`
- **Problem:** RAG pipeline 超参数调优成本高，依赖人工 grid search
- **Method:** LLM agent 自动优化 RAG pipeline 配置；基于 reasoning 驱动的 agent loop
- **Key result:** Matches or beats statistical baselines within first 10 trials（EMNLP 2026 + NeurIPS 2026 workshop accepted）
- *Links:* [PDF](https://arxiv.org/pdf/2610.08452) · [HF](https://huggingface.co/papers/2610.08452)
